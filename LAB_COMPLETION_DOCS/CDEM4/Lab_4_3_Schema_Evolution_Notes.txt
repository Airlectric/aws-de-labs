KEY LEARNINGS:

Backwards Compatibility Rules:
- SAFE: Add optional field (old data still valid, new field = null)
- SAFE: Remove optional field (old data ignores it)
- BREAKING: Add required field (old data missing it fails validation)
- BREAKING: Remove required field (code expecting it breaks)
- BREAKING: Rename required field (old code can't find it)

Avro Union Type:
- ["null","string"] = optional field (null or string)
- First type in union determines default type
- default must match the first type: ["null","string"] → default: null
- To use string default: ["string","null"] → default: "free"

BACKWARD Compatibility Mode:
- New schema versions must be readable by old code
- Ensures no pipeline breaks when schema evolves
- Best choice for production data pipelines

Glue Job Parameters:
- Bucket name passed via --BUCKET job argument (not hardcoded)
- Retrieved in PySpark via getResolvedOptions(sys.argv, ['BUCKET'])
- Makes scripts portable across accounts and environments
